01

What It Does

The VSL Generator is a Claude Project pre-loaded with Mindvalley's entire direct-response playbook. It operates three roles simultaneously.

S

VSL Strategist

Selects the right format, structures the argument arc, sequences conversion triggers across the script, and runs quality checks against 25 master conversion principles.

W

Scriptwriter

Writes camera-ready scripts with stage directions, B-roll cues, text overlay markers, music notes, and timing markers. Ready for production.

L

Lead Creator

Crafts 60-second attention hooks designed as standalone social media videos that also work as VSL openers. Based on Peter Kell's proven lead framework.

Create a new Claude Project

Go to claude.ai and create a new Project. Name it something like "VSL Generator" or "Mindvalley VSL Architect."

2

Paste the System Prompt

Open 00-SYSTEM-PROMPT.txt and paste its entire contents into the project's Custom Instructions field. This tells Claude how to behave, what workflow to follow, and when to reference each document.

3

Upload the 5 Knowledge Documents

Upload these files as Project Knowledge (in this order):

  1. 01-MASTER-CONVERSION-PRINCIPLES.txt
  2. 02-VSL-DNA-LONGFORM.txt
  3. 03-SHORT-FORM-VSL-DNAs.txt
  4. 04-LEAD-BIBLE.txt

4

Start a conversation

Open a new chat within the project. Claude is now ready to write VSLs. Each new conversation in this project will have full access to all the knowledge docs.

Knowledge Base

The system uses a 4-tier document hierarchy. Claude knows which documents to invoke at each stage of the writing process.

Tier 1 — Always Active

Master Conversion Principles

25 universal conversion laws that govern ALL output. Includes the Application Checklist used as the final quality gate before delivery. Think of this as the constitution.

Tier 2 — Format-Specific

VSL DNA (Long-Form + Short-Form)

Two documents with exact structural templates. Long-form has a 9-part DNA structure for 35-minute VSLs. Short-form has timing breakdowns for 3, 5, 10, and 20-minute formats.

Tier 3 — Creative

Lead Bible

Peter Kell's lead framework with 6 core lead types and 25+ real Mindvalley lead scripts. Includes the Robin Sharma lead (highest-performing lead in MV history).

Tier 4 — Voice

Vishen Voice Guide

Vishen's speaking style DNA: sentence structure, tone modes, humor patterns, storytelling techniques, the anti-salesy approach. Applied to ALL output as a style layer.

How the tiers layer: Tier 1 principles govern strategy. Tier 2 provides structure. Tier 3 shapes the opening. Tier 4 polishes the voice. Every script gets all four layers.

Workflow: How Claude Builds a VSL

When you ask Claude to write a VSL, it follows a 9-step process automatically. You'll see it work through each step.

1

Clarify Format

Claude asks: Long-form or short-form? What length? Vishen solo or Vishen + Author?

2

Gather Quest Intelligence

Claude requests the Quest transcript and Quest sales page. Extracts key stories, transformation mechanisms, testimonials, unique methodology, pricing, and bonuses.

3

Identify "The One"

Defines ONE primary narrative, ONE core promise, ONE main emotion, ONE buyer belief. States these explicitly before writing. This is Conversion Principle #1.

4

Select Lead Type

Chooses from Kell's lead types based on Quest content and audience awareness level. Justifies the choice.

5

Map the Structure

Outlines the full script using the appropriate DNA template with time allocations for each section.

6

Write the Script

Applies Vishen's voice. Includes stage directions, B-roll cues, text overlays, music notes, and timing markers. Written in spoken language, not essay language.

7

Embed Conversion Triggers

Verifies against all 25 Master Conversion Principles. Ensures trial closes, open/close loops, and all 4 belief breaks are present.

8

Quality Gate

Runs the Application Checklist from the Master Principles document. Flags any gaps.

9

Deliver

Presents the complete script with: header info, Rule of One statement, full script, conversion trigger map, and suggested A/B test variations.

What to Prepare Before Starting

Have these ready before opening a conversation in the VSL Generator project.

Required

  • Quest transcript (lessons, stories, key content)
  • Quest sales page (positioning, testimonials, pricing, bonuses)
  • Which format: long-form, short-form (specify length), or lead
  • Which presenter format: Vishen solo or Vishen + Author

Helpful (Not Required)

  • Specific testimonials or case studies to feature
  • Any existing leads or hooks that performed well
  • Target audience segment (cold, warm, retargeting)
  • Specific objections this audience has
  • Deadline or scarcity elements to include

Important: If you don't provide the Quest transcript and sales page, Claude will ask for them before writing. It won't guess or fabricate Quest-specific content.

Reading the Output

Scripts use a consistent markup format designed for production teams.

[00:00] [VISHEN TO CAMERA — close-up, direct eye contact] VISHEN: You've been lied to about meditation. [Beat] Not by gurus. Not by apps. By your own brain. [B-ROLL: montage of meditation apps, busy minds] VISHEN: What if I told you there's a method — developed 60 years ago — that can get you into deep meditation in under 10 minutes? [TEXT OVERLAY: "The Silva Method"] [MUSIC: subtle tension build] [TRANSITION: cut to wide shot]

Markup Key

[00:00] Timing marker
[VISHEN TO CAMERA] Stage direction for talent
VISHEN: Presenter name before spoken lines
[Beat] Dramatic pause
[B-ROLL: ...] Visual footage cue
[TEXT OVERLAY: "..."] On-screen text
[MUSIC: ...] Audio/music cue
[TRANSITION: ...] Cut/transition type

Tips & Best Practices

Get the most out of the VSL Generator.

Provide Real Content

The more Quest-specific material you give (transcripts, testimonials, sales pages), the better the output. Claude will use placeholders like [INSERT REAL TESTIMONIAL] when it lacks specifics.

Iterate, Don't Start Over

If the first draft isn't right, tell Claude what to change in the same conversation. It retains context and can refine specific sections without rewriting everything.

Ask for Variations

Request multiple hook or lead variations for A/B testing. Claude can write 3–5 different openings using different lead types for the same Quest.

Review the Conversion Map

Every delivered script includes a conversion trigger map showing where each of the 25 principles appears. Use this to spot gaps before production.

Use for Leads First

If you're new to the tool, start by requesting leads (60-second scripts). They're fast to review and will show you the output quality before committing to a full VSL.

Attach Files, Don't Paste Huge Text

Claude Projects support file attachments in conversations. Attach Quest transcripts as files rather than pasting thousands of words into the chat.

Remember: Claude will never fabricate testimonials, statistics, or Quest-specific claims. If it doesn't have real data, it flags the gap. Always review placeholders before production.

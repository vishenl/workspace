Phase 1

Credits as Optional Overlay

Months 1-6 | Budget: $900K

Objectives

  • Introduce Sparks without disrupting current business
  • Test pricing, earning rates, and member response
  • Build infrastructure and UX
  • Gather data for optimization

Success Metrics

  • Beta member engagement: +40% DAU
  • Program starts: +25%
  • Meditation usage: +100%
  • NPS: Maintain or improve

Implementation Timeline

Month 1-2: Foundation

Build Core Infrastructure

  • Build Spark ledger system (backend)
  • Design and test Spark wallet UI
  • Create dual-pricing display system
  • Set up analytics tracking
Month 3-4: Beta Launch

Limited Release

  • Launch to 10% of members (opt-in)
  • Test earning mechanics
  • Test redemption flows
  • Monitor breakage and engagement
Month 5-6: Expanded Beta

Scale & Optimize

  • Expand to 30% of members
  • Introduce tier multipliers
  • Launch referral Spark program
  • A/B test conversion flows
Phase 2

Credits as Default Currency

Months 7-18 | Budget: $2.65M

Objectives

  • Make Sparks the primary transaction currency
  • Migrate all members to tier-based subscriptions
  • Optimize earning/spending balance
  • Achieve retention and ARPU targets

Success Metrics

  • Active members: 400,000+
  • Retention: 65%+
  • ARPU: $450+
  • Mastery conversions: +100%
  • MRR: $35M+

Implementation Timeline

Month 7-9: Full Rollout

100% Member Migration

  • Launch to 100% of members
  • Grandfather existing members with bonus Sparks
  • Marketing campaign: "Introducing Sparks"
  • Support team training
Month 10-12: Optimization

Data-Driven Refinement

  • Analyze tier distribution
  • Adjust earning rates based on data
  • Launch discovery challenges
  • Implement variable Spark drops
Month 13-15: Premium Push

Mastery & Events Focus

  • Launch Summit → Mastery flow
  • Implement Mastery Goal Tracker
  • Create urgency campaigns for events
  • Introduce Corporate tiers
Month 16-18: Scale

Prepare for Marketplace

  • Launch Creator tiers
  • Optimize breakage (target 18-22%)
  • Refine win-back campaigns
  • Prepare for Phase 3
Phase 3

Marketplace Credit Economy

Months 19-30 | Budget: $3.05M

Objectives

  • Open Spark system to external creators
  • Transform Mindvalley into transformation marketplace
  • Create new revenue streams from commissions
  • Build network effects

Success Metrics

  • Marketplace partners: 200+
  • Partner GMV: $50M+
  • Commission revenue: $10M+
  • Member cross-pollination: 40%+ try partner content

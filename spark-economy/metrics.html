Key Metrics Definitions

Revenue Metrics

Metric Definition Target
MRR Monthly recurring revenue from subscriptions $50M+ (Y2)
ARPU Average revenue per user (annual) $520+ (Y2)
LTV Lifetime value per member $1,500+
CAC:LTV Customer acquisition cost to lifetime value 1:5+

Engagement Metrics

Metric Definition Target
DAU/MAU Daily active / Monthly active users 35%+
Spark Velocity % of Sparks redeemed within 90 days 70-80%
Meditation DAU Daily meditation sessions 40%+ of DAU
Program Starts New programs started per member/year 4+
Program Completions Programs completed per member/year 2.5+

Retention Metrics

Metric Definition Target
Monthly Retention % retained month-over-month 97%+
Annual Retention % retained year-over-year 72%+
Net Revenue Retention Revenue from existing customers YoY 115%+
Churn Rate % canceling per month <3%

Spark Health Metrics

Metric Definition Target
Breakage Rate % of Sparks that expire unredeemed 18-22%
Earn/Spend Ratio Earned Sparks / Spent Sparks 0.3-0.5
Top-up Rate % of members buying additional Sparks 15%+
Tier Upgrade Rate % upgrading tier per year 20%+

System Health Indicators

Healthy Signals

  • Spark velocity 70-80%
  • Breakage 18-22%
  • Tier upgrades > downgrades
  • Referral Sparks growing
  • Meditation streaks increasing

Warning Signals

  • Breakage > 25%
  • Tier downgrades spiking
  • Top-up rate declining
  • Support tickets about Sparks rising
  • NPS declining

Critical Alerts

  • Breakage > 30%
  • Monthly churn > 5%
  • Velocity < 60%
  • Social media backlash
  • Mass cancellation wave

Tracking Framework

Daily Monitoring

  • DAU and meditation sessions
  • Spark transactions (credits/debits)
  • Support ticket volume
  • Error rates in redemption flows

Weekly Review

  • Spark velocity trends
  • Tier distribution changes
  • Top-up conversion rates
  • A/B test results

Monthly Analysis

  • MRR and ARPU trends
  • Churn analysis by tier
  • Breakage rate calculation
  • Cohort retention analysis
  • Mastery/Cert conversion rates

Quarterly Strategic

  • Earn rate optimization
  • Pricing adjustments
  • New feature ROI
  • Competitive analysis
  • Long-term projections

## VIRALITY OPTIMIZATION RULES

### Hook Formula (First 1-3 seconds)
- Pattern interrupt - something unexpected
- Curiosity gap - create a question in their mind
- Bold claim with credibility
- Personal vulnerability that's relatable
- Challenge a common belief

### Hook Structures That Work:
1. **Contrarian:** "Everyone says [X] but here's what actually works..."
2. **Secret:** "All successful people do this but no one talks about it..."
3. **Personal Stakes:** "I spent millions testing this so you don't have to..."
4. **Provocative Question:** "Why do billionaires meditate but never admit it?"
5. **Pattern Interrupt:** Start mid-story, unusual visual cue reference

### Retention Techniques:
- Open loops early ("I'll tell you the third one at the end")
- Use "but" and "however" to create tension
- Numbered lists create commitment ("Here are 3 things...")
- Cliffhangers before key reveals
- Time stamps for longer content

### Pacing Rules:
- First 3 seconds = HOOK (must stop the scroll)
- Seconds 3-10 = SETUP (establish credibility + context)
- Middle = DELIVER VALUE (teach the thing)
- Last 5-10 seconds = CTA or loop back to hook

### Call-to-Action Options:
- "Follow for more on [specific topic]"
- Tie back to mission: "I share this because I believe everyone deserves to learn what successful people know"
- Question for comments: "What's your experience with [topic]?"
- Save prompt: "Save this for when you need it"

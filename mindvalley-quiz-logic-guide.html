1 The 10 Questions

Each question is strategically designed to capture a specific dimension of the user's needs, preferences, and circumstances. Together, they create a comprehensive profile for accurate program matching.

Question 1 • Primary Focus
What's the ONE area of your life you most want to transform this year?
  • Soul & Spirituality category: soul
  • Mind & Mindset category: mind
  • Body & Health category: body
  • Love & Relationships category: relationships
  • Career & Business category: career
  • Performance & Productivity category: performance

Purpose: Determines the PRIMARY program category. 40-50% of recommendations will come from this category.

Question 2 • Life Satisfaction Level
If you rated your overall life satisfaction right now, where would you be?
  • 1-3: Struggling, need significant change level: crisis
  • 4-5: Okay but capable of more level: developing
  • 6-7: Good but want next level level: growing
  • 8-10: Thriving, want to optimize level: optimizing

Purpose: Determines program INTENSITY and APPROACH. Lower scores = foundational programs. Higher scores = advanced/optimization programs.

Question 3 • Biggest Challenge
What's the #1 challenge holding you back?
  • Stress, anxiety, or overwhelm challenge: stress
  • Lack of clarity on purpose/direction challenge: purpose
  • Low energy or health issues challenge: energy
  • Struggling with confidence/self-worth challenge: confidence
  • Relationship problems or loneliness challenge: love
  • Financial stress or career stagnation challenge: money
  • Inability to focus or stay consistent challenge: focus
  • Feeling spiritually disconnected challenge: spiritual

Purpose: CRITICAL for program matching. Each challenge maps to specific programs designed to address it.

Question 4 • Time Available
How much time can you realistically dedicate daily to personal growth?
  • 10-15 minutes time: minimal
  • 20-30 minutes time: moderate
  • 45-60 minutes time: dedicated
  • 60+ minutes time: immersive

Purpose: Filters programs by DURATION and LESSON LENGTH. Ensures recommendations fit user's schedule.

Question 5 • Learning Style
What type of learning resonates most with you?
  • Practical & action-oriented style: practical
  • Scientific & evidence-based style: scientific
  • Spiritual & transformational style: spiritual
  • Balanced mix of both style: balanced

Purpose: Matches users with TEACHERS and METHODOLOGIES that align with their preferred approach.

Question 6 • Experience Level
How would you describe your personal development journey?
  • Just getting started experience: beginner
  • Exploring (read some books, tried things) experience: exploring
  • Committed (regularly invest in growth) experience: intermediate
  • Advanced (years of practice) experience: advanced

Purpose: Determines program DIFFICULTY LEVEL. Prevents beginners from advanced programs (frustration) and advanced from beginner programs (boredom).

Question 7 • Desired Timeline
When do you want to see meaningful results?
  • Within 1-2 weeks timeline: quick
  • Within 1-2 months timeline: short
  • Within 3-6 months timeline: medium
  • Committed to full year timeline: long

Purpose: Affects PROGRAM SEQUENCING. Quick timeline = shorter programs first. Long timeline = can include comprehensive programs.

Question 8 • Core Motivation
Which statement resonates most with your "why"?
  • Feel happier and more at peace motivation: peace
  • Achieve bigger goals, make more money motivation: achievement
  • Better relationships, deeper connections motivation: connection
  • More energy, feel amazing in my body motivation: vitality
  • Find purpose, make an impact motivation: purpose
  • Unlock full potential, peak performance motivation: performance

Purpose: Reveals the EMOTIONAL DRIVER behind transformation. Used to personalize messaging and select outcome-aligned programs.

Question 9 • Program Intensity
How do you prefer to learn?
  • Light & easy (short lessons, minimal homework) intensity: light
  • Moderate (daily lessons with exercises) intensity: moderate
  • Intensive (comprehensive with deep work) intensity: intensive
  • Immersive (all-in transformation) intensity: immersive

Purpose: Filters by PROGRAM WORKLOAD. Prevents overwhelm by matching commitment preference.

Question 10 • Starting Approach
How would you like to begin your journey?
  • Quick win first start: quickwin
  • Build a foundation start: foundation
  • Deep dive into biggest challenge start: deepdive
  • Holistic approach (multiple areas) start: holistic

Purpose: Determines the FIRST PROGRAM recommendation and overall journey structure.

2 Scoring System

The algorithm uses a weighted scoring system where each program receives points based on how well it matches user responses across all 10 dimensions.

Base Score Formula

Program Score = (Category Match × 30) + (Challenge Match × 25) + (Style Match × 15) + (Level Match × 10) + (Time Fit × 10) + (Motivation Alignment × 10) // Maximum possible score: 100 points

Score Breakdown by Factor

Factor Max Points Matching Logic
Category Match 30 Full points if program category = Q1 answer. 15 points for secondary categories from motivation.
Challenge Match 25 Full points if program directly addresses Q3 challenge. Partial for related challenges.
Style Match 15 Full points for exact style match. "Balanced" matches all styles at 10 points.
Level Match 10 Full points for exact match. -3 for one level difference. -7 for two+ levels.
Time Fit 10 Full points if lesson duration fits daily time. Scaled based on program length.
Motivation Alignment 10 Full points if program outcomes align with Q8 motivation statement.
💡
Bonus Points
Programs can earn bonus points (+5) for: matching preferred teachers, being marked as "trending" or "highly rated", or having high completion rates for similar user profiles.

4 Matching Algorithm

The algorithm runs in multiple phases to ensure optimal program selection and sequencing.

Phase 1: Initial Filtering

Eliminate programs that are definite mismatches:

  • Remove programs requiring more time than user has (Q4)
  • Remove programs 2+ levels above user experience (Q6)
  • Remove programs with incompatible learning style if user is not "balanced" (Q5)

Phase 2: Score Calculation

For each remaining program, calculate the weighted score:

function calculateScore(program, answers) { let score = 0; // Category match (30 pts max) if (program.category === answers.primaryFocus) { score += 30; } else if (program.category === getSecondaryCategory(answers.motivation)) { score += 15; } // Challenge match (25 pts max) if (program.challenges.includes(answers.biggestChallenge)) { score += 25; } else if (program.challenges.some(c => relatedChallenges[answers.biggestChallenge].includes(c))) { score += 12; } // Style match (15 pts max) if (answers.learningStyle === 'balanced' || program.style.includes(answers.learningStyle)) { score += 15; } // Level match (10 pts max) const levelDiff = Math.abs(levelMap[program.level] - levelMap[answers.experience]); score += Math.max(0, 10 - (levelDiff * 3)); // Time fit (10 pts max) if (program.dailyMinutes <= timeMap[answers.timeAvailable]) { score += 10; } // Motivation alignment (10 pts max) if (program.outcomes.includes(answers.motivation)) { score += 10; } return score; }

Phase 3: Selection & Diversity

Select top programs while ensuring diversity:

  • Programs 1-4: Highest scoring from PRIMARY category
  • Programs 5-6: Highest scoring from SECONDARY category (based on motivation)
  • Programs 7-8: Highest scoring that address specific CHALLENGE
  • Programs 9-10: Fill with highest remaining for HOLISTIC coverage

Phase 4: Sequencing

Order the 10 programs based on Q10 (Starting Approach):

Starting Approach First Program Logic Progression Pattern
Quick Win Shortest program (1-2 weeks) from top matches Short → Medium → Long → Medium
Foundation Foundational program (Lifebook, 6 Phase, Be Extraordinary) Foundation → Build → Specialize → Advanced
Deep Dive Highest scoring program for their #1 challenge Primary Challenge → Related → Expand
Holistic Lifebook Online (covers all 12 life areas) Rotate through categories systematically

5 Question Weights & Impact

Not all questions have equal influence on the final recommendations. Here's how each question impacts the algorithm:

Question Weight Impact Type What It Determines
Q1: Primary Focus HIGH Category Selection 40-50% of programs come from this category
Q2: Life Satisfaction MEDIUM Program Intensity Beginner vs advanced program filtering
Q3: Biggest Challenge HIGH Program Matching Specific program selection, first program choice
Q4: Time Available HIGH Filtering Hard filter - eliminates programs that don't fit
Q5: Learning Style MEDIUM Teacher/Method Matches to program methodology
Q6: Experience Level MEDIUM Difficulty Prevents mismatch frustration/boredom
Q7: Timeline LOW Sequencing Program order and duration mix
Q8: Motivation MEDIUM Secondary Category Adds programs from motivation-aligned category
Q9: Intensity LOW Workload Fine-tunes program selection within matches
Q10: Starting Approach HIGH First Program Determines which program is recommended FIRST
⚠️
Critical Questions
Q1, Q3, Q4, and Q10 are the most influential. If a user skips or gives unclear answers to these, the algorithm's accuracy drops significantly. Consider making these required.

8 Implementation Code

Here's the complete JavaScript implementation of the recommendation algorithm:

// Program Database Structure const programDatabase = { programs: [ { id: 'silva-ultramind', title: 'The Silva Ultramind System', author: 'Vishen Lakhiani', category: 'soul', duration: '4 weeks', dailyMinutes: 30, level: 'intermediate', style: ['spiritual', 'balanced'], challenges: ['purpose', 'focus'], outcomes: ['peace', 'purpose'], intensity: 'moderate' }, // ... more programs ] }; // Main Recommendation Function function getRecommendations(answers) { // Step 1: Filter programs let eligible = programDatabase.programs.filter(p => { // Time filter if (p.dailyMinutes > timeMap[answers.timeAvailable]) return false; // Level filter (allow 1 level difference) const levelDiff = Math.abs(levelMap[p.level] - levelMap[answers.experience]); if (levelDiff > 1) return false; // Style filter (unless balanced) if (answers.learningStyle !== 'balanced' && !p.style.includes(answers.learningStyle)) return false; return true; }); // Step 2: Score each program const scored = eligible.map(p => ({ ...p, score: calculateScore(p, answers) })).sort((a, b) => b.score - a.score); // Step 3: Select with diversity const selected = []; const usedIds = new Set(); // Get top 4 from primary category scored.filter(p => p.category === answers.primaryFocus) .slice(0, 4) .forEach(p => { selected.push(p); usedIds.add(p.id); }); // Get top 2 from secondary category const secondary = getSecondaryCategory(answers.motivation); scored.filter(p => p.category === secondary && !usedIds.has(p.id)) .slice(0, 2) .forEach(p => { selected.push(p); usedIds.add(p.id); }); // Get top 2 challenge-specific scored.filter(p => p.challenges.includes(answers.biggestChallenge) && !usedIds.has(p.id)) .slice(0, 2) .forEach(p => { selected.push(p); usedIds.add(p.id); }); // Fill remaining with highest scored scored.filter(p => !usedIds.has(p.id)) .slice(0, 10 - selected.length) .forEach(p => selected.push(p)); // Step 4: Sequence based on starting approach return sequencePrograms(selected, answers.startingApproach); } // Sequencing Logic function sequencePrograms(programs, startingApproach) { switch(startingApproach) { case 'quickwin': // Sort by duration (shortest first) return programs.sort((a, b) => getDurationWeeks(a) - getDurationWeeks(b)); case 'foundation': // Put foundational programs first const foundational = ['lifebook', '6-phase', 'be-extraordinary']; return programs.sort((a, b) => { const aFound = foundational.includes(a.id) ? 0 : 1; const bFound = foundational.includes(b.id) ? 0 : 1; return aFound - bFound; }); case 'deepdive': // Keep original score order (highest challenge match first) return programs; case 'holistic': // Rotate through categories return rotateByCategory(programs); } }

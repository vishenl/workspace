# Thumbnail Archetypes - Prompt Templates

## Archetype 1: THE REACTION
**Best For:** Surprising content, unexpected reveals, shocking facts

### Nano Banana 3 Template
```
Extreme close-up portrait of a [age] [gender] with an expression of complete shock and disbelief, wide eyes, open mouth, raised eyebrows, looking directly at camera, [skin tone] skin, [hair description], dramatic side lighting creating strong shadows, vibrant orange and teal color grading, photorealistic, editorial portrait photography, highly detailed eyes catching light, sharp focus, 16:9 aspect ratio
```

### MidJourney Template
```
Stunning portrait of person in absolute shock, jaw dropped, eyes wide with disbelief, dramatic cinematic lighting, vibrant color grading, editorial photography, expressive face, emotional intensity --ar 16:9 --v 6 --style raw
```

## Archetype 2: THE BEFORE/AFTER
**Best For:** Transformation content, tutorials, results-focused videos

### Nano Banana 3 Template
```
Split image composition, left side showing [before state with specific details], right side showing [after state with specific details], clear visual contrast, professional studio lighting, the before side slightly desaturated, the after side vibrant and bright, clean background, product photography style, sharp division line in center, 16:9 aspect ratio
```

### MidJourney Template
```
Dramatic before and after transformation, split composition, [before description] versus [after description], contrasting lighting and color, professional photography, clear visual storytelling --ar 16:9 --v 6
```

## Archetype Selection Guide

| Content Type | Best Archetype |
|--------------|----------------|
| Shocking facts/reveals | REACTION |
| Weight loss/makeover | BEFORE/AFTER |
| "You won't believe" | CURIOSITY GAP |
| How-to/tutorial | AUTHORITY |
| Challenge/stunt | SPECTACLE |
| Day in my life | LIFESTYLE |
| Interview reaction | REACTION |
| Course/coaching | AUTHORITY |
| Hidden secret | CURIOSITY GAP |
| Results/proof | BEFORE/AFTER |
